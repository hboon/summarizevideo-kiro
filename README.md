# SummarizeVideo.ai Power for Kiro

Turn a public technical talk, tutorial, or demo into notes you can check against the video. The Power shows Kiro how to use your SummarizeVideo.ai summary and transcript to cite timestamps, check quotes, and save notes as Markdown.

1. [Set up the SummarizeVideo.ai MCP connection](standalone/README.md) in your Kiro workspace.
2. In the Kiro IDE Powers panel, choose **Add Custom Power** and import this repository. To install a specific version, download that release and choose **Import power from a folder**. [Kiro Power installation](https://kiro.dev/docs/powers/installation/).
3. Ask Kiro to use SummarizeVideo to turn a completed tutorial summary into notes with timestamps. Give it the request ID from the `q` parameter in your summary link and ask it to check the transcript before quoting.

Use a **Read only** key to work with summaries already in your account. Start processing new public videos only when you want to use your account's allowance or an existing pass credit.
